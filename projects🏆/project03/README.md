# project03: 스타벅스 마케팅 프로모션 성과 분석

## 목표
프로모션 유형 및 채널별 성과 데이터를 분석하여 마케팅 비용을 효율화하고 ROI를 최적화한다.

## 기간
2025.10.30. ~ 2025.11.11 (13일)

## 데이터
- 출처: [Starbucks Customer Data](https://www.kaggle.com/datasets/ihormuliar/starbucks-customer-data/data) / 캐글
- 파일명: portfolio.csv 외 2개 (약 28MB)

## 주요 작업
- 데이터 ERD 구성
- 데이터 전처리, EDA
- 통계검정
- 모델링(분류)
- 대시보드(tableau)
- 인사이트 도출
