# project02: 배송 지연 요인 분석 및 개선 전략

## 목표
배송 품질 향상을 통하여 소비자 이탈 방지를 유도한다.

## 기간
2025.10.13. ~ 2025.10.23 (11일)

## 데이터
- 출처: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) / 캐글
- 파일명: olist_orders_dataset.csv 외 8개 (약 120MB)

## 주요 작업
- 데이터 ERD 구성
- 데이터 전처리, EDA
- 모델링(회귀 & 군집)
- 인사이트 도출
