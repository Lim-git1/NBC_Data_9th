# project01: 친환경 내연 차량의 효율적인 설계 전략 제안

## 목표
차량 유형별 성능 차이를 비교 분석하여 친환경 차량 설계안을 제시한다.

## 기간
2025.09.04. ~ 2025.09.12 (9일)

## 데이터
- 출처: [Fuel Consumption 2000-2022](https://www.kaggle.com/datasets/ahmettyilmazz/fuel-consumption/data) / 캐글
- 파일명: Fuel_Consumption_2000-2022.csv (약 1.5MB)

## 주요 작업
- 데이터 파악
- 데이터 전처리
- EDA, 시각화
- 인사이트 도출
