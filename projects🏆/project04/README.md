# project04: 100대 명산 통합 분석을 통한 개인화 추천 플랫폼 구축

## 목표
사용자 유형에 따라 가장 적합한 산과 등산 코스를 추천하는 데이터 기반 의사결정 도구 개발한다.

## 기간
2025.11.24. ~ 2025.12.30 (38일)

## 데이터
- [한국등산트레킹지원센터_산림청 100대명산](https://www.data.go.kr/data/15098177/fileData.do?recommendDataYn=Y) / 공공데이터포털
- [국토교통부_전국 버스정류장 위치정보](https://www.data.go.kr/data/15067528/fileData.do) / 공공데이터포털
- [국내 지역별 관광명소데이터](https://www.bigdata-culture.kr/bigdata/user/data_market/detail.do?id=1ec19f06-035e-49f3-8c5d-ff8d2d2829a7) / 문화빅데이터플랫폼
- 그 외 수집 데이터(네이버 블로그 본문, 유튜브 댓글, 네이버지도 리뷰, 카카오맵 리뷰, 카카오맵 POI)

## 주요 작업
- 데이터 수집
- 데이터 파생변수 생성
- LLM을 통한 NLP
- 통계검정
- 모델링(군집)
- 대시보드(streamlit)
